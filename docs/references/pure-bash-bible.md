# Pure Bash Bibleの関数選定

## 対象

この文書は、Pure Bash Bibleを参照した公開関数の契約と、採用しない名前付き関数の理由を記載します。参照元のコードは実行時依存として読み込みません。

## 採用する関数

| 参照元 | 本プロジェクトの関数 | 機能 |
|---|---|---|
| `trim_string` | `string::trim` | 先頭と末尾の空白文字を除き、結果を標準出力へ書きます。 |
| `trim_all` | `string::collapse-whitespace` | 両端の空白文字を除き、内側で連続する空白文字をASCII空白一つへ変換します。 |
| `regex` | `regex::is-match` | 文字列がBashの`[[ =~ ]]`が解釈するPOSIX拡張正規表現に一致するかを終了状態で返します。 |
| `split` | `string::split` | 文字列を空でない区切り文字列で分割し、空の要素を保持して一要素ずつ標準出力へ書きます。 |
| `lower` | `string::lower` | ASCII英大文字を小文字へ変換し、その他の文字を保持します。 |
| `upper` | `string::upper` | ASCII英小文字を大文字へ変換し、その他の文字を保持します。 |
| `reverse_case` | `string::swap-case` | ASCII英字の大文字と小文字を入れ替え、その他の文字を保持します。 |
| `trim_quotes` | `string::strip-surrounding-quotes` | 文字列全体を囲む同種の引用符を一組だけ除きます。 |
| `strip_all` | `string::remove-all-matches` | Bashパターンに一致する部分をすべて除きます。 |
| `strip` | `string::remove-first-match` | Bashパターンに最初に一致する部分を除きます。 |
| `lstrip` | `string::remove-prefix` | Bashパターンに一致する最長の接頭部分を除きます。 |
| `rstrip` | `string::remove-suffix` | Bashパターンに一致する最長の接尾部分を除きます。 |
| `urlencode` | `string::encode-url` | UTF-8文字列をバイト単位でパーセント符号化します。 |
| `urldecode` | `string::decode-url` | 正しいパーセント符号化をバイトへ戻します。 |
| 文字列包含の条件式 | `string::contains` | 第一引数が第二引数をリテラル文字列として含むかを終了状態で返します。 |
| 接頭辞の条件式 | `string::starts-with` | 第一引数が第二引数で始まるかを終了状態で返します。 |
| 接尾辞の条件式 | `string::ends-with` | 第一引数が第二引数で終わるかを終了状態で返します。 |
| `dirname` | `path::directory-name` | パスのディレクトリ部分を標準出力へ書きます。 |
| `basename` | `path::base-name` | パスの最後の要素を標準出力へ書き、指定した接尾辞を一度だけ除けます。 |

## 採用しない名前付き関数

| 参照元 | 機能 | 不採用の理由 |
|---|---|---|
| `bar` | 端末上へ進捗バーを描画します。 | 端末UIは製品固有の表示機能です。 |
| `bkr` | コマンドをバックグラウンド実行して出力を破棄します。 | プロセスの分離と出力の破棄を暗黙に行います。 |
| `count` | グロブ展開後のファイルまたはディレクトリを数えます。 | 結果が呼び出し側のシェル設定に依存します。 |
| `cycle` | グローバル配列の要素を巡回します。 | 呼び出し間でグローバル状態を変更します。 |
| `date` | Bashの日時書式で現在日時を出力します。 | Bash 3.2では同じ組み込み日時書式を使用できません。 |
| `do_something` | 関数宣言構文を示します。 | 固定された契約を持つ関数ではありません。 |
| `extract` | マーカー間のファイル行を出力します。 | 区間とマーカーの扱いが製品要件に依存します。 |
| `f` | 配列反転と短縮した関数宣言を示します。 | 独立した一つの契約を持ちません。 |
| `get_cursor_pos` | 端末のカーソル座標を読み取ります。 | 対話端末と端末エミュレーターに依存します。 |
| `get_functions` | 定義済みの関数名を出力します。 | デバッグとシェル内省のための機能です。 |
| `get_term_size` | 端末の行数と列数を出力します。 | 端末UI専用であり、シェルオプションへ作用します。 |
| `get_window_size` | 端末画面のピクセル寸法を読み取ります。 | 端末の対応状況と応答時間に依存します。 |
| `head` | ファイルの先頭から指定行数を出力します。 | ファイル行処理は製品要件に依存し、標準コマンド名とも衝突します。 |
| `hex_to_rgb` | 16進カラーコードをRGB値へ変換します。 | 色の変換は製品表示の責務です。 |
| `is_hex_color` | 16進カラーコードを検証します。 | 色専用の入力検査です。 |
| `lines` | ファイル全体を配列へ読み込み、行数を出力します。 | Bash 4専用構文を使用し、ファイル全体をメモリーへ保持します。 |
| `lines_loop` | ファイルを一行ずつ読み取り、行数を出力します。 | 最終行の扱いが製品要件に依存します。 |
| `random_array_element` | 配列要素を疑似乱数で選択します。 | 再現性と暗号学的な安全性を保証できません。 |
| `read_sleep` | 外部の`sleep`を使わずに待機します。 | ファイル記述子とプロセス置換へ依存します。 |
| `remove_array_dups` | 連想配列で重複要素を除きます。 | Bash 3.2では連想配列を使用できず、元の実装は順序を保持しません。 |
| `reverse_array` | `BASH_ARGV`を使って配列要素を逆順にします。 | `extdebug`と互換モードへ依存します。 |
| `rgb_to_hex` | RGB値を16進カラーコードへ変換します。 | 色の変換は製品表示の責務です。 |
| `tail` | ファイルの末尾から指定行数を出力します。 | ファイル行処理は製品要件に依存し、標準コマンド名とも衝突します。 |
| `to_upper` | 呼び出し元の変数を大文字へ書き換えます。 | Bash 4の名前参照へ依存し、呼び出し元の変数を変更します。 |
| `uuid` | `$RANDOM`でUUID形式の文字列を生成します。 | 識別子に必要な安全性と衝突耐性を保証できません。 |

# Lobashの関数選定

## 対象

この文書は、Lobash v0.7.0を参照し、採用する振る舞いと採用しないモジュールを記載します。
採用した振る舞いは、BashStockの公開契約へ合わせた独立実装として扱います。

Pure Bash Bibleから採用した関数と同じ責務を持つLobashモジュールは重ねて採用しません。`.p`で終わるパイプライン版と`.s`で終わる文字列真偽値版も、元の関数と別の公開関数にはしません。

## 共通規則

採用関数は、利用者の値を`eval`へ渡しません。関数は、グローバル変数、現在のディレクトリ、`IFS`、ロケール、シェルオプションを呼び出し後に変更しません。

述語関数は、条件が成立すると終了状態0、成立しないと1、引数または入力形式が不正な場合は64を返します。述語関数は標準出力と標準エラー出力へ書きません。値を返す関数は結果だけを標準出力へ書きます。

配列要素を標準出力へ書く関数は、一要素を一行として扱います。改行を含む要素は終了状態64を返します。Bash 4の連想配列、名前参照、大小文字変換、`mapfile`を使用する元実装は、Bash 3.2の添字配列、反復処理、パラメーター展開、組み込みの`printf`で置き換えます。

対話入力関数は、メッセージと選択肢を標準エラー出力へ書き、標準入力から一行だけ読みます。関数内では再入力を繰り返しません。入力が契約に合わない場合は終了状態64、入力前にEOFへ到達した場合は66を返します。製品は、対話入力を使用するかどうか、再入力を求めるかどうか、非対話実行を許可するかどうかを決定します。

時間関数は、macOS、Ubuntu、Fedoraで同じ関数名、UTC日時とローカル日時の出力形式、整数の丸め規則、終了状態を使用します。公開関数はすべて`time`名前空間に置きます。内部時計アダプターはPerlの`Time::HiRes`と`POSIX`を使用し、GNU版とBSD版で異なる`date`コマンドのオプションへ依存しません。必要な実行環境を利用できない場合は、診断を標準エラー出力へ書き、終了状態69を返します。

#### 対話入力APIの共通契約

| 公開関数 | 引数 | 正常時の出力 |
|---|---|---|
| `prompt::confirm` | `MESSAGE [DEFAULT]`。`DEFAULT`は`yes`または`no`です。 | 入力を`yes`または`no`へ正規化します。空入力では指定された既定値を出力します。 |
| `prompt::read-line-with-default` | `MESSAGE DEFAULT` | 空でない入力はそのまま出力し、空入力は`DEFAULT`を出力します。 |
| `prompt::confirm-or-cancel` | `MESSAGE [DEFAULT]`。`DEFAULT`は`yes`、`no`、`cancel`のいずれかです。 | 入力を`yes`、`no`、`cancel`のいずれかへ正規化します。空入力では指定された既定値を出力します。 |
| `prompt::select-one` | `MESSAGE ITEM...`。一つ以上の`ITEM`が必要です。 | 1から始まる選択番号に対応する`ITEM`をそのまま出力します。 |

メッセージ、既定値の案内、選択肢は標準エラー出力へ書き、結果だけを標準出力へ書きます。`DEFAULT`を省略した確認関数へ空入力を渡した場合は終了状態64を返します。入力に改行がないままEOFへ到達した場合でも、EOFより前に読み取った文字列を一行として処理します。入力内容を画面へ表示しない秘密入力には使用しません。

| 公開関数 | 時計 | 出力 |
|---|---|---|
| `time::monotonic-milliseconds` | スリープを除外する単調時計 | システムが動作した時間を0以上のミリ秒整数で出力します。実時間時計の変更による影響を受けません。 |

| `time::local-date-time-milliseconds` | 実時間時計 | プロセスのローカル日時を`YYYY-MM-DDTHH:MM:SS.sss+HH:MM`または`YYYY-MM-DDTHH:MM:SS.sss-HH:MM`形式で出力します。小数部は常に3桁です。 |
| `time::local-date-time-seconds` | 実時間時計 | プロセスのローカル日時を`YYYY-MM-DDTHH:MM:SS+HH:MM`または`YYYY-MM-DDTHH:MM:SS-HH:MM`形式で出力します。 |

| `time::unix-days` | 実時間時計 | Unixエポックからの経過ミリ秒を86,400,000で割り、小数部分を切り捨てたUTCの経過日数を10進整数で出力します。 |

時間関数は引数を受け取りません。引数がある場合は終了状態64を返します。ミリ秒値は高分解能時計から取得します。単調時計はスリープを除外し、起動後時計はスリープを含みます。どちらも実時間時計の変更による影響を受けません。UTC日時、ローカル日時、Unix時刻は実時間時計を使用するため、システム日時の変更を反映します。

ローカル日時は、`TZ`環境変数が設定されている場合はそのタイムゾーン、設定されていない場合はOSに設定されたタイムゾーンを使用します。日時にはタイムゾーンの略称を含めず、その日時で有効なUTCオフセットを`+HH:MM`または`-HH:MM`形式で含めます。夏時間の開始と終了では、同じタイムゾーンでもUTCオフセットが変わります。

内部時計アダプターは、単調時計、起動後時計、実時間時計のミリ秒値と、UTC日時およびローカル日時の固定形式をmacOS、Ubuntu、Fedoraへ同じ形式で返します。Linuxの起動後時計は`/proc/uptime`を使用します。macOSでは単調時計に`CLOCK_UPTIME_RAW`、起動後時計に`CLOCK_MONOTONIC_RAW`を使用します。テストでは全環境で次の境界値と形式を確認します。

| テスト対象 | 必須条件 |
|---|---|
| macOS | Apple Silicon上の標準Bash 3.2で、時間APIの出力、終了状態、単位境界を確認します。 |
| Ubuntu | Ubuntu 18.04以降のBashで、時間APIの出力、終了状態、単位境界を確認します。 |
| Fedora | Fedora 44のBashで、時間APIの出力、終了状態、単位境界を確認します。 |
| ミリ秒境界 | 999、1,000、1,001ミリ秒を使用し、秒への切り捨てを確認します。 |
| 日境界 | 86,399,999、86,400,000、86,400,001ミリ秒を使用し、日への切り捨てを確認します。 |
| UTC日付境界 | UTCの月末、年末、うるう日の直前と直後を確認します。 |
| ローカル日時 | `TZ=UTC`、`TZ=Asia/Tokyo`、`TZ=America/New_York`で同じ固定時刻を変換し、日付、時刻、UTCオフセットを確認します。 |
| 夏時間 | 夏時間の開始直前と直後、終了直前と直後について、ローカル時刻とUTCオフセットを確認します。 |
| 時計の変更 | 実時間時計が変更されても、単調時計と起動後時計が影響を受けないことを確認します。 |
| 実行環境不足 | Perl、`Time::HiRes`、`POSIX`のいずれかを利用できない場合に終了状態69を返すことを確認します。 |

| `benchmark` | 指定コマンドを複数回実行して所要時間を測定します。 | 任意コマンドの反復実行、副作用、ウォームアップ、時計の選択を含むため、専用ベンチマークとして分離します。 |
| `compose` | 複数の関数またはコマンド文字列を合成して実行します。 | 動的なコマンド文字列の実行が必要になり、入力をコードとして扱わない規則に反するためです。 |
| `parse_args` | 連想配列の定義からオプションと位置引数を解析します。 | 各公開関数の`while` / `case`と`arg::`検査関数が同じ責務を担当し、Bash 3.2に連想配列もないためです。 |
| `parse_params` | オプションと位置引数を配列へ格納します。 | Lobashでも非推奨であり、`while` / `case`と`arg::`検査関数の責務と重複します。 |
| `repeat` | 指定コマンドを指定回数だけ実行します。 | 任意コマンドの動的実行と副作用を隠すため、呼び出し側で通常のループを記述します。 |
| `sedi` | GNU版とBSD版の`sed -i`差異を吸収してファイルを直接編集します。 | ファイルを破壊的に書き換え、任意の`sed`式も受け取るため、標準ライブラリの共通関数にしません。 |
| `trap_error` | エラー発生時のファイル名と行番号を表示するトラップを設定します。 | グローバルな`ERR`トラップを上書きし、呼び出し側のエラー処理方針へ作用するためです。 |
| `with_ifs` | 一時的な`IFS`を指定してコマンド文字列を実行します。 | コマンド文字列の評価が必要になり、入力をコードとして扱わない規則に反するためです。 |

### Variable

| 参照元 | 機能 | 不採用の理由 |
|---|---|---|
| `cur_function_name` | 呼び出し元の関数名を出力します。 | デバッグと内省のための機能であり、利用者向けCLIの公開機能に含めません。 |
| `random` | 指定文字集合から任意長のランダム文字列を生成します。 | 外部の`dd`へ依存し、暗号学的な安全性も保証しないため、識別子や秘密値の生成に使用できません。 |
| `var_attrs` | 指定変数の`declare`属性を出力します。 | 変数名の間接参照とBashのバージョン差へ依存し、Bash 3.2向け公開APIに必要ありません。 |
